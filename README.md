# 📱 QR Text Generator

A lightweight Python CLI tool that converts text or URLs into QR code images.

## Features

- Convert text into QR codes
- Support URLs
- Custom output filename
- Generate PNG images
- Simple CLI interface

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Example

```text
Enter text or URL: https://github.com
Enter output filename: github.png

✅ QR code saved as github.png
```

## Built With

- Python
- qrcode
- Pillow
